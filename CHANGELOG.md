# Журнал изменений

## Подготовка к сдаче

- Валидация обязательных полей сообщает раздел, номер записи и ожидаемый тип. Сохранённые проверки прежнего формата доступны для просмотра.
- На графе можно выбрать дату подписания, отдельно посмотреть связи вне выбранной даты и открыть основания каждого звена. У частных контрактов отдельное обозначение.
- Изменение только имени проверяющего сохраняется и отражается в журнале. Повтор того же решения не создаёт события.
- Windows-лаунчер выбирает свободный порт, переиспользует свою копию и предоставляет отдельную команду остановки.

## Предыдущие изменения

- Валидация идентификаторов, календарных границ и связей по источникам.
- Раздельные идентификаторы сигналов по повторным сведениям о годовом доходе.
- Переход из сигнала на граф, выделение цепочки, фильтрация и поиск пути.
- Источники, связанные объекты, решения и итог рассмотрения в HTML-отчёте.
- Корректная очистка временных баз Windows, сериализация обновлений и миграций.
- Локальный запуск в отдельном окне Windows и архив с включённым окружением.
