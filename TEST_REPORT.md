# Проверка выпуска для сдачи

Среда проверки — Windows x64, Python 3.13.5, Streamlit 1.67.0, Chrome.

- Исходная копия прошла 78 тестов. После исправлений прошли 89 тестов. Регрессии охватывают обязательные поля JSON, восстановление после ошибки загрузки, истёкшие отношения, частный контракт, происхождение связей и изменение только имени проверяющего.
- Приёмочный скрипт воспроизвёл четыре сценария с 0, 1, 2 и 6 сигналами. Проверены граф, целостность базы и отчёты.
- Chrome при 1280×720 проверил замену некорректного файла, открытие графа на дату подписания, историю изменения имени, повторное сохранение без события и выгрузку HTML и JSON.
- При занятом порте 8517 лаунчер выбрал 8518, сохранил исходного владельца порта и при повторном запуске переиспользовал свой сервер. Полная остановка завершает этот сервер. При следующем запуске данные берутся из той же SQLite.
- Запуск проверялся в папке с пробелами и кириллицей. При использовании командного файла сервер был доступен. Появление отдельного окна Edge на интерактивном рабочем столе и запуск на втором компьютере требуют отдельного подтверждения.

Тесты используют синтетические данные. Контрольные суммы подтверждают согласованность внутри локальной базы.
