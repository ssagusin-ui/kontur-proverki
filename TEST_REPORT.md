# Отчёт о тестировании аналитики и браузерного запуска

Среда проверки — Windows x64, Python 3.13.5, Streamlit 1.67.0, Chrome. В этом отчёте приведены результаты проверки аналитики и запуска через командный файл. Проверка отдельного Windows-приложения описана в [отчёте об оконной сборке](desktop/TEST_REPORT.md).

- До исправлений успешно выполнялись 78 тестов, после исправлений — 89. Регрессионные тесты охватывают обязательные поля JSON, восстановление после ошибки загрузки, завершившиеся отношения, частный контракт, происхождение связей и изменение только имени проверяющего.
- Приёмочный скрипт воспроизвёл четыре сценария с 0, 1, 2 и 6 сигналами. Проверены граф, целостность базы и отчёты.
- В Chrome при размере окна 1280×720 проверены замена некорректного файла, открытие графа на дату подписания, история изменения имени, повторное сохранение без нового события и выгрузка HTML и JSON.
- При занятом порте 8517 лаунчер выбрал 8518. Процесс, занимавший порт 8517, продолжил работу. При повторном запуске лаунчер использовал уже работающий сервер своей копии. Команда полной остановки завершила этот сервер. При следующем запуске данные были прочитаны из той же базы SQLite.
- Запуск проверялся в папке с пробелами и кириллицей. При использовании командного файла подтверждена доступность сервера. Появление отдельного окна Edge на интерактивном рабочем столе и запуск на втором компьютере в рамках этой проверки остались неподтверждёнными.

Тесты используют синтетические данные. Контрольные суммы подтверждают согласованность внутри локальной базы.
