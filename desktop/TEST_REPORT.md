# Отчёт о тестировании Windows-приложения

Среда — Windows x64, Python 3.13.5 из архива, Microsoft WebView2 Runtime 157.0.4341.60.

- Распакованная сборка прошла 89 тестов и четыре приёмочных сценария. Проверка зависимостей pip завершилась успешно.
- Исполняемый файл открыл отдельное окно на интерактивном рабочем столе. В интерфейсе WebView2 проверены сценарий семейной цепочки, граф на дату контракта, сохранение решения и журнал.
- Закрытие окна приложения остановило его сервер. После перезапуска из той же базы SQLite были загружены сохранённые имя проверяющего, статус и комментарий.
- При экспорте в обычной сборке появился системный диалог с предложенным именем HTML-отчёта. В автоматической проверке HTML и JSON сохранены через обработчик WebView2 с заранее заданной папкой. В обоих файлах проверены комментарий и имя. В JSON также проверены статус и согласованность журнала.
- Интерактивное подтверждение пути в системном диалоге и запуск на другом компьютере не проверялись.

В архив включены штатный исполняемый файл приложения, переносимое окружение Python и лицензия SDK WebView2. Средства диагностики, использованные при проверке экспорта, в исполняемый файл выпуска не включены.
