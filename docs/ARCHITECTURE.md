# Архитектура

## Обработка данных

Приложение принимает JSON-файл или встроенный синтетический набор. Модуль `core/domain.py` проверяет входные данные и нормализует JSON, чтобы контрольная сумма одного и того же снимка воспроизводилась. Правила в `core/rules.py` сопоставляют идентификаторы лиц и объектов с учётом дат и сведений об источниках.

Модуль `core/graph.py` строит ориентированный граф с помощью NetworkX. Plotly отображает выбранную цепочку и соседние узлы. При повторном открытии проверки приложение читает сигналы из SQLite и восстанавливает граф по сохранённому снимку. Результаты рассмотрения доступны в HTML и JSON.

## Хранение и целостность

SQLite хранит снимки проверок, решения специалиста и события журнала. Первое событие записывается в одной транзакции с созданием проверки. При изменении решения его новая версия и событие журнала также сохраняются вместе. Новые поля схемы добавляются с сохранением существующих записей.

Контрольные суммы SHA-256 позволяют проверить согласованность снимка и журнала в пределах одной базы. Для независимого аудита контрольные суммы потребовалось бы хранить отдельно.

## Локальный запуск

В Windows интерфейс Streamlit работает на локальном сервере. Переносимая сборка открывает его в окне WebView2. При запуске через `start_windows.cmd` интерфейс открывается в окне Edge или в системном браузере.

Встроенные случаи содержат только синтетические сведения. Для работы с реальными данными потребуются авторизация, защищённое хранение, правовые основания для подключения источников и регламент работы с ними.
