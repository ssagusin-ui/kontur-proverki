# Архитектура

JSON / демонстрационный набор → валидация → правила и граф → рассмотрение человеком → SQLite → HTML и JSON.

Входные данные проверяются в core/domain.py. JSON нормализуется для детерминированного хеширования. Правила core/rules.py получают согласованные идентификаторы лиц и объектов, даты и сведéния об источниках. NetworkX строит ориентированный граф в core/graph.py. Plotly отображает выделенную цепочку и окрестность аналитического сигнала. Страница результатов считывает сохранённые сигналы из SQLite и строит граф на сохранённом входном снимке.

SQLite хранит проверки, решения и события. Создание набора и первое событие записываются в одной транзакции. Обновление решения и добавление события выполняются вместе. Схема расширяется добавлением полей с сохранением старых строк. SHA-256 сопоставляет снимки и журнал внутри одной базы. Для доверенного аудита потребовалось бы независимое хранение контрольных сумм.

Windows-лаунчер запускает Streamlit на локальном интерфейсе и открывает окно Edge. Конкурсный сценарий использует только синтетические данные. Промышленное развёртывание потребует авторизации, защищённого хранения, интеграций с правовыми основаниями и отдельного регламента.
