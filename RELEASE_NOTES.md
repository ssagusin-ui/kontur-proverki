# «Контур проверки» 1.0.0

Выпуск для хакатона «Код прозрачности» включает переносимое приложение для Windows x64. Распакуйте `Kontur-Windows-x64.zip`, откройте папку `Kontur` и запустите «Контур проверки.exe». Интерфейс откроется в отдельном окне Windows.

Для этого выпуска проверены Python 3.13.5, Streamlit 1.67.0, NetworkX 3.7, Plotly 6.9.0 и pandas 3.1.1. Интерпретатор и библиотеки входят в архив. Для окна необходим Microsoft WebView2 Runtime.

Порядок запуска из исходников и запасной способ запуска через `start_windows.cmd` приведены в [руководстве](README.md). Условия испытаний и результаты собраны в [отчёте о проверке Windows-приложения](desktop/TEST_REPORT.md).
